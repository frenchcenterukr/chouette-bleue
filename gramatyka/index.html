QUESTIONS

Кілька важливих деталей

Який рівень потрібен для навчання?

Курс буде корисним для будь-якого рівня з повного нуля до впевненого володіння французькою.

Скільки триває навчання?

Навчання триває один місяць, уроки відкриваються через день, доступ до курсу залишається відкритим впродовж трьох місяців.

Чи перевіряє викладач домашні завдання?

Так, передбачена обов'язкова перевірка домашнього завдання та індивідуальний зворотний зв'язок із рекомендаціями.

Чи є живі онлайн-зустрічі?

Так, один раз на тиждень проходять групові Zoom-сесії з викладачем у форматі питання — відповіді.
